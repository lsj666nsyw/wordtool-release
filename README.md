# Word 批量处理助手

Windows 桌面工具，批量处理 Word 文档（DOCX）。

## 功能

- **批量替换** — 在所有段落、表格、页眉页脚中查找替换文字
- **提取图片** — 从 DOCX 中提取所有内嵌图片
- **文档统计** — 段落数、表格数、图片数、字符数
- **文档合并** — 多个 DOCX 合并为一个
- **水印** — 文字/图片水印，透明度/旋转可调
- **导出文本** — DOCX 导出为纯文本

## 使用方法

1. 下载 `Word批量处理助手_v1.0.zip`
2. 解压到文件夹
3. 双击 `Word批量处理助手.exe`
